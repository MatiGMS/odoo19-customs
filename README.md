# odoo19-customs
Personalizaciones a medida para Odoo en su versión 19

kpi_product_lines_global_view

## Funcionalidad:
Se añade un desarrollo a medida, consiste en una vista que nos permite acceder a un nuevo menú, en el que podemos ver una vista global de todas las líneas de entregas globales en un solo lugar. Sirve para tener otra perspectiva de cada producto entregado por la empresa.
